# Sales Dashboard

## Project Overview

An interactive Sales Dashboard developed using Python and Streamlit to analyze sales data and generate meaningful business insights.

## Tools & Technologies

- Python
- Pandas
- Streamlit
- Data Analysis
- Data Visualization

## Key Analysis

- Sales performance analysis
- Product-wise sales analysis
- Sales trends
- Customer/order analysis
- Interactive filtering and visualization

## Project Files

- `appp.py` – Streamlit application
- `train.csv` – Dataset used for analysis
- `Sales.jpg` – Dashboard preview
